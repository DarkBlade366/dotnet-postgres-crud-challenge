# DotNet PostgreSQL CRUD Challenge

## Descripción
Proyecto de aprendizaje para dominar C#, .NET y PostgreSQL, implementando un CRUD completo.

## Objetivos del Proyecto
- Aprender sintaxis y estructura de C# (OOP)
- Conectar .NET con PostgreSQL
- Implementar operaciones CRUD
- Crear una API REST con 3 entidades relacionadas

## Estructura del Proyecto
- **Entidad 1:** Student
- **Entidad 2:** Course
- **Relación:** Un estudiante puede estar en muchos cursos y un curso puede tener muchos estudiantes

## Timeline de Aprendizaje
1. **Días 1-3:** PostgreSQL fundamentals
2. **Días 4-5:** C# syntax
3. **Días 6-8:** .NET + PostgreSQL CRUD
