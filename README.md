# DotNet PostgreSQL CRUD Challenge

## Descripción
Proyecto de aprendizaje para dominar C#, .NET y PostgreSQL, implementando un CRUD completo con Entity Framework Core.

## Objetivos del Proyecto
- Aprender sintaxis y estructura de C# (OOP)
- Conectar .NET con PostgreSQL
- Implementar operaciones CRUD
- Crear una API REST con 2 entidades relacionadas

## Estructura del Proyecto
- **Entidad 1:** Producto
- **Entidad 2:** Categoría
- **Relación:** Un Producto pertenece a una Categoría

## Timeline de Aprendizaje
1. **Días 1-3:** PostgreSQL fundamentals
2. **Días 4-5:** C# syntax & OOP
3. **Días 6-8:** .NET + PostgreSQL CRUD
